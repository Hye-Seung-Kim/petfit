PawTry Together - demo video

Place your prerecorded dog video here, named exactly:

    dog-demo.mp4

Full path: public/demo/dog-demo.mp4

Requirements:
- MP4 container, H.264 video (plays natively in Chrome)
- A few seconds to a couple of minutes is plenty
- Keep the dog reasonably centered/still for a few frames so a clean
  capture frame is easy to grab during the demo

This file is intentionally NOT included in the repository (no copyrighted
media is downloaded automatically). If it's missing, the host UI will show
a notice and let you upload any local MP4 file instead via the "Upload
Video" button - the demo file is just a convenience shortcut.
